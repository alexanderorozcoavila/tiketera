Instrucciones:
1.- Debes crear una aplicacion web con las siguientes caracteristicas:
    Lenguaje: Python
    Framework: Django
    Base de datos: sqlite3
2.- La aplicacion debe tener las siguientes funcionalidades:
    - debe estar configurado el administrador de django
    - debe tener un sistema de autenticacion de usuarios
    - debe tener registro de usuarios
    - debe tener login de usuarios
    - debe tener logout de usuarios
    - debe tener recuperacion de contraseña
    - debe tener un sistema de gestion de eventos
    - debe tener un sistema de gestion de boletos
    - los boletos deben tener un identificador unico, este debe generarse mediante token de ethereum
    - al imprimir los boletos estos codigos deben ser unicos y no repetibles y se debe mostrar un codigo QR
    - debe tener un sistema de gestion de pagos
    - debe tener un sistema de notificaciones
    - debe tener un sistema de reportes
    - debe tener un sistema de auditoria
    - debe tener un sistema de logs
    - debe tener un sistema de seguridad
    - debe tener un sistema de roles
    - debe tener un sistema de permisos
    - toda la gestion administrativa debe realizarse mendiante el administrador de django
    - debe tener un sistema de integracion con la blockchain de ethereum
